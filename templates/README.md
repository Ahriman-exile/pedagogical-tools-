## 🎯 Назначение

Папка `templates/` содержит:

✅ **Шаблон конспекта** — для создания новых уроков
✅ **Шаблон презентации** — для слайдов
✅ **Шаблон теста** — для проверки знаний
✅ **Шаблон рубрики** — для критериев оценки
✅ **Шаблон плана** — для структурирования курса

---

## 📝 Типы шаблонов

1. **Markdown шаблоны** — для текстового контента
2. **PowerPoint шаблоны** — для презентаций
3. **Excel шаблоны** — для данных и оценок
4. **Google Docs** — для совместной работы

---

## ✍️ Как использовать

1. Скопируйте нужный шаблон
2. Переименуйте файл
3. Заполните своим контентом
4. Сохраните в соответствующей папке
