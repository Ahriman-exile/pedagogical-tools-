## 📝 Типы оценивания

### 1. Объективные тесты

**Форма:** Множественный выбор, верно/неверно, заполнение пропусков

**Преимущества:**
- Легко проверить
- Объективное оценивание
- Быстрая обратная связь

### 2. Субъективные тесты

**Форма:** Эссе, задачи на решение, проекты

**Преимущества:**
- Проверяет критическое мышление
- Показывает понимание
- Развивает письменную речь
