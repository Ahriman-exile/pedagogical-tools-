## Как вносить изменения в CHANGELOG

При добавлении новых материалов или функций:

1. **Добавьте запись** в раздел `[Unreleased]` под соответствующую подкатегорию:
   - `Added` — новые материалы или функции
   - `Changed` — изменения в существующих материалах
   - `Fixed` — исправление ошибок
   - `Removed` — удаление устаревших материалов
   - `Deprecated` — материалы, которые скоро будут удалены

2. **Используйте эмодзи** для визуализации:
   - 📚 — материалы и конспекты
   - 📊 — презентации
   - ✅ — тесты
   - 🔧 — инструменты
   - 🐛 — исправления
   - 📝 — документация
   - ✨ — новые функции

3. **Создавайте релизы** при достижении значимых вех

### Пример записи
```markdown
### Added
- 📚 Конспект лекции по теме "Основы программирования"
- 📊 Презентация к уроку информатики
- ✅ Тест для проверки знаний студентов

### Changed
- 📝 Обновлена структура папки templates/
```

## Версионирование

Используется формат: `[MAJOR].[MINOR].[PATCH]`

- **MAJOR** — значительные изменения в структуре или концепции
- **MINOR** — добавление нового контента или функций
- **PATCH** — небольшие исправления и обновления

Пример: `0.1.0` → `0.2.0` → `0.2.1` → `1.0.0`
