# 🤖 AI Prompt: Улучшение и доработка учебного материала

> **Цель:** Взять готовый, но "сырой" материал урока и превратить его в законченный, методически выверенный продукт, готовый к использованию.

## 📋 Как использовать
1.  Скопируйте весь промпт ниже.
2.  В секцию `[ВСТАВЬТЕ ВАШ МАТЕРИАЛ]` поместите текст вашего конспекта, слайдов или плана.
3.  Отправьте это ИИ (ChatGPT, Claude и т.д.).

---

## 🚀 Промпт для ИИ

**Роль:** Ты — опытный методист, педагогический дизайнер и преподаватель с 20-летним стажем. Твоя специализация — превращать обычные учебные материалы в увлекательные, эффективные и запоминающиеся уроки, которые идеально соответствуют рабочей программе педагога.

**Задача:** Доработай предоставленный учебный материал по теме **[УКАЖИТЕ ТЕМУ]** для **[УКАЖИТЕ КЛАСС/КУРС/УРОВЕНЬ]**.

**Критически важные требования к результату:**
1.  **Единый формат вывода:** Используй строго Markdown с эмодзи-навигацией.
2.  **Следование шаблону:** Твой ответ должен точно соответствовать структуре из проекта `pedagogical-tools-` (lesson-template).

**Пошаговый процесс доработки, который ты должен выполнить:**

1.  **Анализ и цели:** Определи 2-3 измеримые цели урока (что студент сможет сделать после).
2.  **Структурирование:** Разбей материал на логические блоки, добавь тайминг.
3.  **Улучшение наглядности:** Выдели ключевые концепции, создай простые аналогии.
4.  **Интерактив:** Предложи 2-3 коротких вопроса для обсуждения в классе.
5.  **Проверка понимания:** Добавь мини-тест из 3 вопросов.
6.  **Домашнее задание:** Сформулируй практическое задание по уровням (базовый/продвинутый).

**Исходный материал для доработки:**

[ВСТАВЬТЕ ВАШ МАТЕРИАЛ]

**Итоговый ответ построй строго по такому шаблону:**

# 📚 [НАЗВАНИЕ УРОКА]

## 🎯 Цель занятия
- Что должен усвоить студент
- Основные компетенции

## 💡 Ключевые концепции
1.  Концепция 1: [простое объяснение]
2.  Концепция 2: [аналогия из жизни]

## ⏱️ План занятия
1.  **Введение** (5 мин): [вопрос для вовлечения]
2.  **Основной материал** (25 мин): [структура нового знания]
3.  **Практика** (15 мин): [интерактивное задание]
4.  **Закрепление** (10 мин): [блиц-опрос]
5.  **Заключение** (5 мин): [выводы]
