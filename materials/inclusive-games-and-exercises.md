## 🎨 Сенсорные игры

Для работы с детьми, которым нужна сенсорная стимуляция или сенсорная регуляция.

### 1. "Волшебная коробка"

**Для кого:** Дети с нарушениями зрения, РАС, ЗПР

**Что нужно:**
- Коробка или непрозрачный мешок
- Разные текстурные предметы (мягкие, жесткие, гладкие, шероховатые)

**Как играть:**

```
1. Ребенок закрывает глаза (или использует повязку)
2. Опускает руку в коробку
3. Трогает предмет и угадывает, что это
4. Вытаскивает и проверяет
5. Все повторяют с другим предметом

ВАРИАНТЫ ПРЕДМЕТОВ:
- Мягкие: мех, ватные диски, пух
- Жесткие: камень, деревянный куб, металл
- Гладкие: стекло, шелк, керамика
- Шероховатые: наждачная бумага, ткань, корзинка
```

**Адаптации:**
- 👂 Для слабослышащих: показываем картинку, что могут быть в коробке
- 🚑 Для ДЦП: поддерживаем руку
- 🧠 Для РАС: предупреждаем, что будет неожиданно, даем выбор
- 🧠 Для ЗПР: даем 2 варианта ответа

---

### 2. "Сенсорные бутылочки"

**Для кого:** Все категории, особенно для успокоения

**Что нужно:**
- Прозрачные бутылочки
- Вода
- Блестки, бисер, песок, цветные бусинки
- Пищевые красители

**Как делать:**

```
1. Заполняем бутылочку на половину водой
2. Добавляем краситель (несколько капель)
3. Добавляем предметы (блестки, бусинки)
4. Закрываем крышку, склеиваем скотчем

ВАРИАНТЫ:
- Спокойная (медленно падают блестки) - для релаксации
- Активная (много движущихся деталей) - для стимуляции
- Шумная (с бусинками и рисом) - для слабовидящих
```

**Как использовать:**
- Дети встряхивают, смотрят, слушают
- Успокаивает перед сном
- Может быть "станция для перезагрузки"

---

### 3. "Радуга-текстура"

**Для кого:** Дети с нарушениями зрения, РАС, обогащение сенсорного опыта

**Что нужно:**
- Разноцветные ткани (красная, оранжевая, желтая, зеленая, синяя, фиолетовая)
- Разные текстуры (каждого цвета)

**Как играть:**

```
1. Показываем красную ткань (мягкую)
2. Ребенок трогает, говорит "мягкая"
3. Показываем красную ткань (жесткую)
4. Ребенок трогает, сравнивает
5. Повторяем с каждым цветом

РАЗВИТИЕ ИГРЫ:
- Называем цвета (для обычных детей)
- Ищем ткань по описанию: "Мягкая и красная"
- Сортируем по цветам
- Сортируем по текстурам
```

**Адаптации:**
- Слабовидящие описывают вслух, что чувствуют
- Глухие видят демонстрацию, затем сами делают
- РАС: предварительно покажите все ткани
- На коляске: ткани на удобной высоте

## 💬 Коммуникативные игры

Для развития общения, речи и социальных навыков.

### 1. "Что я вижу?"

**Для кого:** Развитие речи, обычные дети, дети с ЗПР

**Что нужно:**
- Коробка или мешок
- Разные предметы

**Как играть:**

```
ВОСПИТАТЕЛЬ: "Я вижу [предмет]"
ДЕТИ: Угадывают, что это
ВОСПИТАТЕЛЬ: Вытаскивает предмет
ДЕТИ: "Правильно! Это [предмет]"

РАЗВИТИЕ:
- Давайте больше подсказок
- Дети сами выбирают предмет и описывают
- Категоризируем: "овощи", "игрушки", "одежда"
```

**Адаптации:**
- 👂 Глухие/слабослышащие: показываем жесты для предметов
- 🧠 РАС: показываем картинку до угадывания
- 🧠 ЗПР: даем 2-3 варианта ответа
- 🎤 Если молчит: принимаем жесты, ноддинг, указание пальцем

---

### 2. "Угадай эмоцию по лицу"

**Для кого:** Развитие эмоциональной грамотности, дети с РАС

**Что нужно:**
- Карточки с эмоциями (счастье, грусть, гнев, страх, удивление)
- Зеркало (опционально)

**Как играть:**

```
1. Показываем карточку с эмоцией
2. Воспитатель показывает лицо
3. Дети повторяют выражение
4. Говорим: "Это [эмоция]"
5. Дети называют времена, когда они так чувствуют

ВАРИАНТЫ:
- "Покажи мне счастье"
- "Как выглядит грусть?"
- "Что вызывает страх?"
```

**Адаптации:**
- 👂 Глухие видят демонстрацию, используем жесты
- 🚑 ДЦП: может кивать вместо повторения
- 🧠 РАС: практикуем по очереди, медленно
- 😠 Дети с проблемами поведения: учим выражать эмоции здоровым способом

---

### 3. "Волшебные руки" (жестовая коммуникация)

**Для кого:** Включение всех детей в коммуникацию, обогащение

**Что нужно:**
- Себя (свои руки)
- Желание учить жесты

**Как учить жесты:**

```
ЖИВОТНЫЕ:
- КОРОВА: указываем рога (два пальца вверху)
- СОБАКА: движение ушей (рука к голове)
- ПТИЦА: движение крыльев (рука в стороне, вверх-вниз)

ДЕЙСТВИЯ:
- ЕСТЬ: движение к рту
- СПАТЬ: рука под щеку
- ИГРАТЬ: движение рук в стороны

БАЗОВЫЕ:
- ДА: киваем головой + кулак
- НЕТ: мотаем головой + палец вперед
- ПРИВЕТ: помахали рукой
- СПАСИБО: рука от сердца к человеку
```

**Как использовать:**
- Все дети (слышащие и глухие) используют одни жесты
- Развивает инклюзию и взаимопонимание
- Полезно при шуме (на прогулке, в зале)
- Помогает детям с проблемами речи

## 🏃 Подвижные игры

### 1. "Животные"

**Для кого:** Все категории

**Как играть:**

```
УРОВЕНЬ 1 (Сидя/на коляске):
- Показываем животное
- Ребенок показывает движение (махи руками для крыльев)
- Издаем звук

УРОВЕНЬ 2 (Стоя):
- Ходим как животное
- Издаем звук
- Перемещаемся по комнате

УРОВЕНЬ 3 (Активный):
- Быстро движемся
- Танцуем как животное
- Мимика лица

ВАРИАНТЫ ЖИВОТНЫХ:
- Корова: идем медленно, "МУ"
- Заяц: прыгаем, "ПРЫ"
- Птица: машем руками, летим
- Медведь: рычим, ходим медленно
- Лошадь: цокаем, рысь
```

**Адаптации:**
- 👂 Слабослышащие видят движения, может быть вибрация
- 🚑 На коляске: верхняя часть тела, руки, голова
- 🧠 РАС: показываем, затем даем время на повторение
- 😠 Проблемы поведения: структурированная игра, четкие правила

---

### 2. "Музыкальные стульья - адаптивная верс��я"

**Для кого:** Все, но адаптивно

**Как играть:**

```
КЛАССИЧЕСКИЙ ВАРИАНТ:
1. Ставим стулья в круг
2. Музыка играет, дети ходят
3. Музыка остановилась - сели на стул
4. Один стул убираем каждый раунд

АДАПТИВНЫЙ ВАРИАНТ 1 (Для коляски):
- Стулья в два ряда
- Ребенок на коляске находит место между стулами
- Вместо сидения - занимает место в кругу

АДАПТИВНЫЙ ВАРИАНТ 2 (Для молчаливых):
- Вместо музыки - визуальный сигнал (флаг, свет)
- Вместо сидения - встать на разноцветный коврик
- Дети разных категорий садятся вместе

АДАПТИВНЫЙ ВАРИАНТ 3 (Для РАС):
- Предусмотрено место отдыха
- Не выбывают, а переходят на другой стул
- Четкие сигналы начало/конец
- Похвала за спокойное участие
```

---

### 3. "Парашют"

**Для кого:** Все категории, развитие сотрудничества

**Что нужно:**
- Большой парашют или простынь (можно использовать скатерть)

**Как играть:**

```
1. Все встают (или сидят) в кругу, держат края
2. Вместе поднимаем вверх - "ВДОХ"
3. Опускаем - "ВЫДОХ"
4. Кладем мяч сверху, пытаемся его подбросить
5. Волны: все вместе делаем волны

ВАРИАНТЫ:
- Палатка: опускаем парашют вниз, прячемся
- Прыгающие мячи: несколько мячей скачут
- Танец: делаем волны под музыку
- Совместное дыхание: синхронное поднятие-опускание
```

**Почему это хорошо:**
- Все держатся за край - все вовлечены
- На коляске может держать край
- Не нужны сложные движения
- Отличное совместное занятие
- Развивает командный дух

## 🎨 Творческие упражнения

### 1. "Рисование всем телом"

**Для кого:** Все, особенно дети с гиперактивностью и РАС

**Что нужно:**
- Большой лист бумаги (можно несколько)
- Краски (безопасные, моющиеся)
- Защита одежды

**Как делать:**

```
ВЕРСИЯ 1 - На полу:
- Большой лист на полу
- Краски вокруг
- Дети встают на лист и танцуют
- Следы краски на бумаге - "танцевали"

ВЕРСИЯ 2 - На стене:
- Лист на стене
- Разные уровни для разного роста
- Дети рисуют рукой, ногой, всем телом

ВЕРСИЯ 3 - Совместный рисунок:
- Один большой лист на полу
- Все дети рисуют вместе
- Каждый в своей зоне
- Потом смотрим, что получилось - "вместе создали"
```

**Адаптации:**
- 👂 Глухие участвуют наравне
- 🚑 На коляске: на удобной высоте, краски адаптированные
- 👁️ Слабовидящие: используем контрастные краски, гуще
- 🧠 ЗПР: более толстые кисти, меньше вариантов цветов
- 😠 Проблемы поведения: структурированное пространство, не переступают границу

---

### 2. "Коллаж из текстур"

**Для кого:** Все, развитие мелкой моторики и сенсорики

**Что нужно:**
- Большой лист бумаги
- Клей (водорастворимый, безопасный)
- Разные материалы: ткани, бумага, фольга, наждачная бумага, нитки и т.д.

**Как делать:**

```
УРОВЕНЬ 1:
- Материалы уже вырезаны большие
- Ребенок выбирает и клеит
- Воспитатель помогает с клеем

УРОВЕНЬ 2:
- Материалы нарезаны
- Ребенок сортирует (мягкие/жесткие, большие/маленькие)
- Затем клеит

УРОВЕНЬ 3:
- Ребенок сам вырезает материалы
- Создает картину
- Могут быть узнаваемые формы
```

**Адаптации:**
- Для ДЦП: большие куски, толстый клей-карандаш (не жидкий)
- Для слабовидящих: материалы с разными текстурами, контрастные цвета
- Для РАС: предварительный выбор материалов, чтобы не переполнять
- Для ЗПР: много похвалы, пошаговая инструкция

## 🧠 Когнитивные игры

### 1. "Логические пары"

**Для кого:** Обычные дети, дети с ЗПР

**Что нужно:**
- Карточки с парами (2 одинаковые)
- Коробка

**Как играть:**

```
ВЕРСИЯ 1 - Память:
- Все карточки вниз лицом
- Открываем по 2
- Ищем пару
- Если найдена - берем

ВЕРСИЯ 2 - Ассоциации:
- Открыты все карточки
- Задание: "Найди маму теленка" (корова - теленок)
- Дети ищут связь

ВЕРСИЯ 3 - Категории:
- Карточки по категориям: животные, еда, одежда
- Сортируем в группы
- Названиваем категории
```

**Карточки могут быть:**
- Картинки животных
- Еда и животное
- Части и целое (колесо и машина)
- Действия и результат

---

### 2. "Что лишнее?"

**Для кого:** Развитие логики, обычные дети

**Как играть:**

```
ВОСПИТАТЕЛЬ ПОКАЗЫВАЕТ:
- Корова, собака, коза, апельсин
- Вопрос: "Что лишнее?"
- Ответ: "Апельсин, потому что это не животное"

ВАРИАНТЫ:
- Красное яблоко, красный помидор, красный мяч, синий мяч
  Лишнее: синий мяч (не красный)
  
- Стол, стул, кровать, машина
  Лишнее: машина (мебель vs транспорт)
```

**Адаптации:**
- 🧠 ЗПР: даем картинки + словесно
- 🧠 РАС: меньше вариантов (3 вместо 4)
- 👂 Слабослышащие: показываем жесты категорий

## 😊 Игры на эмоциональное развитие

### 1. "Коробка чувств"

**Для кого:** Все, разви��ие эмоциональной грамотности

**Что нужно:**
- Коробка
- Карточки с эмоциями и ситуациями

**Как играть:**

```
1. Вытаскиваем карточку: "Ты упал и сделал больно"
2. Вопрос: "Какое чувство?"
3. Ответ: "Боль, грусть"
4. Говорим: "Что можем сделать?" (позвать взрослого, дыхание и т.д.)
5. Повторяем с другой ситуацией

ПРИМЕРЫ СИТУАЦИЙ:
- Прилетела бабочка
- Взяли твою игрушку
- Мама пришла за тобой
- Потерял друга в толпе
- Получил подарок
- Никто не хочет играть со мной
```

**Адаптации:**
- Глухие/слабослышащие: показываем жесты эмоций
- ДЦП: может кивнуть на вариант ответа
- Дети с проблемами речи: показывают эмоцию лицом, жестами

---

### 2. "Мирилка"

**Для кого:** Все, развитие конфликт-менеджмента

**Как делать:**

```
КОГДА КОНФЛИКТ:
1. Два ребенка сидят рядом (или воспитатель между ними)
2. Берут "мирилку" (мягкую игрушку, помпон, цветок)
3. По очереди говорят: "Мне не нравилось, когда ты..."
4. Затем: "Давай будем друзьями"
5. Обнимаются или пожимают руки

ВАРИАНТ С ЖЕСТАМИ:
- Можно показывать, что произошло
- Жестами объяснить
- Затем мирились

ВАРИАНТ БЕЗ СЛОВ:
- Глухие дети объясняют жестами
- Слышащие дети повторяют жесты
- Вместе мирятся
```

**Почему это помогает:**
- Структурирует конфликт
- Учит выражать эмоции
- Обучает примирению
- Инклюзивно - все могут участвовать

---

### 3. "Волшебное зеркало"

**Для кого:** Развитие уверенности, особенно дети с ЗПР и низкой самооценкой

**Что нужно:**
- Реальное или нарисованное зеркало
- Позитивные утверждения

**Как делать:**

```
1. Ребенок смотрит в "зеркало" (на фото себя)
2. Воспитатель говорит: "Я вижу красивого, умного Миши"
3. Ребенок повторяет или кивает
4. Смотрим на другого ребенка
5. Ребенок говорит про него что-то хорошее

ПРИМЕРЫ:
- "Я вижу сильного Саши"
- "Я вижу добрую Ольгу"
- "Я вижу быстрого Игоря"
- "Я вижу веселого Макса"
```

**Почему это работает:**
- Повышает самооценку
- Учит видеть хорошее в других
- Позитивный язык
- Все участвуют, все слышат хорошее про себя

## 📊 Рекомендации по использованию

### Когда использовать:

```
НАЧАЛО ДНЯ:
- Коммуникативные игры (привет, как дела)
- Эмоциональные игры (как ты себя чувствуешь)

ОСНОВНОЕ ВРЕМЯ:
- Когда нужна энергия: подвижные игры
- Когда нужна концентрация: когнитивные игры
- Когда нужно творчество: творческие упражнения

КОНЕЦ ДНЯ:
- Сенсорные игры для успокоения
- Эмоциональные игры (рефлексия)
- Мирные игры

КОГДА НУЖНА "ПЕРЕЗАГРУЗКА":
- Сенсорные бутылочки
- Парашют
- Волшебное зеркало (для уверенности)
```

### Для разных категорий детей:

```
👂 СЛАБОСЛЫШАЩИЕ/ГЛУХИЕ:
- Жестовые коммуникативные игры
- Подвижные игры (видят и чувствуют)
- Сенсорные игры
- Творческие без звука

👁️ СЛАБОВИДЯЩИЕ/СЛЕПЫЕ:
- Сенсорные игры (тактильные, звуковые)
- Коммуникативные (голос, жесты)
- Подвижные (звуковые сигналы, тактильные ориентиры)
- Описательные творческие (лепка, рельефные)

🚑 ДЦП:
```
