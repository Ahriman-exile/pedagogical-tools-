## ✍️ Как создать конспект

### Шаг 1: Скопируйте шаблон

```bash
cd lessons/[subject]/
cp ../lesson-template.md [номер]-[название].md
```

### Шаг 2: Заполните основную информацию

Отредактируйте:
- Название темы
- Цель занятия
- Длительность
- Необходимые материалы

### Шаг 3: Добавьте содержание

Следуйте структуре шаблона.

### Шаг 4: Добавьте в Git

```bash
git add [номер]-[название].md
git commit -m "Add lesson: [название на русском]"
git push
```
