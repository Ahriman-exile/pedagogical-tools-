## 🎯 О проекте

**Pedagogical Tools** — это централизованное хранилище учебных материалов и инструментов, разработанное для:

✅ **Организации контента** — структурированное хранение всех педагогических материалов в одном месте

✅ **Экономии времени** — готовые шаблоны и примеры для быстрого создания новых материалов

✅ **Стандартизации** — единый формат и структура материалов

✅ **Повторного использования** — легко найти и переиспользовать материалы

✅ **Автоматизации** — использование ИИ-помощников для ускорения подготовки материалов

✅ **Версионирования** — отслеживание всех изменений и обновлений через Git

### 🎓 Для кого это полезно?

- 👨‍🏫 Учителя и преподаватели
- 👩‍💼 Тьюторы и менторы
- 🏫 Образовательные центры
- 📚 Авторы курсов и учебников
- 🤖 Разработчики с педагогическими целями

## 🚀 Быстрый старт

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/Ahriman-exile/pedagogical-tools-.git
cd pedagogical-tools-
```

### 2️⃣ Изучение структуры

```bash
# Посмотрите содержимое
ls -la

# Или откройте в редакторе
code .  # для VS Code
```

### 3️⃣ Начните с примеров

1. Откройте папку `templates/`
2. Посмотрите шаблоны в `markdown-template.md`
3. Скопируйте шаблон в нужную папку
4. Заполните его своим контентом

### 4️⃣ Используйте AI-подсказки

Откройте `ai-prompts/` и найдите подсказку для вашей задачи:
- Генерация конспекта занятия
- Создание теста
- Написание домашнего задания

## 📖 Как использовать

### Создание нового конспекта занятия

```bash
# 1. Перейдите в нужную папку
cd lessons/

# 2. Создайте файл (используйте шаблон)
cp ../templates/lesson-template.md ./01-introduction.md

# 3. Заполните содержимое
# Используйте эмодзи и структурированный формат

# 4. Добавьте в Git
git add 01-introduction.md
git commit -m "Add lesson: Introduction to Topic"
```

### Добавление презентации

```bash
# 1. Сохраните презентацию в presentations/
presentations/topic-name.pdf

# 2. Создайте README для ссылки на неё
cd presentations/
touch topic-name.md

# 3. Добавьте описание и ссылку
# Используйте markdown для документирования
```

### Создание теста

```bash
# 1. Используйте шаблон
cp ../templates/quiz-template.md ./test-001.md

# 2. Заполните вопросы и ответы
# Структурируйте по сложности

# 3. Добавьте ключ ответов в tests/solutions/
```

## 💡 Примеры

### Структура конспекта занятия

```markdown
# 📚 Название темы

## Цель занятия
- Что должен усвоить студент
- Основные компетенции

## Ключевые концепции
1. Концепция 1
2. Концепция 2
3. Концепция 3

## План занятия
1. **Введение** (5 мин)
2. **Основной материал** (25 мин)
3. **Практика** (15 мин)
4. **Закрепление** (10 мин)
5. **Заключение** (5 мин)

## Материалы
- [Ссылка на ресурс](url)
- [Книга](url)

## Домашнее задание
- Задача 1
- Задача 2
```

```markdown
# Генерация конспекта через ИИ

Включи:
- Цель урока
- Ключевые концепции (3-5)
- Пошаговый план (30-45 минут)
- Интерактивные элементы
- Домашнее задание
- Рекомендуемые ресурсы

Формат: Markdown"
```

## ⭐ Рекомендации

### 📝 Лучшие практики

✅ **Используйте единый формат** — все файлы в markdown для простоты

✅ **Добавляйте эмодзи** — делает материалы более наглядными

✅ **Структурируйте иерархию** — используйте заголовки H1, H2, H3

✅ **Добавляйте ссылки** — на источники, дополнительные материалы

✅ **Версионируйте изменения** — пишите понятные commit messages

✅ **Документируйте всё** — особенно сложные концепции

### 🚫 Избегайте

❌ Смешивание разных форматов в одном файле

❌ Очень большие файлы (>500 строк) — разбейте на части

❌ Неструктурированный текст — используйте списки и таблицы

❌ Отсутствие исходников — сохраняйте первоисточники
