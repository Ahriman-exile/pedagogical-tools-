Teacher Assistant Repository

Репозиторий для хранения и организации учебных материалов.

Структура

- lessons/ — конспекты занятий
- presentations/ — презентации
- tests/ — тесты и контрольные
- homework/ — домашние задания
- materials/ — дополнительные материалы
- ai-prompts/ — полезные запросы для ИИ

Цель

Создать удобную цифровую систему для работы педагога и автоматизации рутины.
